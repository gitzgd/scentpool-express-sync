# ADR-0009：发货方案独立于门店归属，批次配置不可变

- 状态：接受
- 日期：2026-10-04

## 背景

总部履约迁移到中台，但仍需保留原门店网点。仅改全局地址会让排队任务或失败重试使用新地址/网点，也可能复用旧请求号取得原面单。

## 决策

增加两套固定公司配对的可编辑发货方案，复用快递100菜鸟授权和原打单队列。选择在预览和取号之前完成，批次创建事务保存逐项私有配置快照。Worker 和重试只读该快照，取消复用既有授权快照；已有面单不通过重印变更发货地。

初版默认方案初始为空，需在生产网点核实、备份及上线后显式配置。历史未保存快照的失败项禁止盲目重试或改用新方案。原门店/团队权限、业务分类和历史订单不变。

2026-10-10 根据用户新要求更新：增加昆明顺丰速运 `kunming_sf`，沿用同一菜鸟授权、独立模板；统计仍归入昆明渠道。新批次一律手动选择，不设任何默认；清空原 `default_profile_id` 配置但保留列，前后端均禁止默认兜底。顺丰模板可稍后补填，缺基础模板时阻止新下单，不影响已有任务的快照重试。此变更不扩展多账号模型。

## 影响

SQLite 只做增量迁移；快照包含业务联系人和授权，仅保留在受控数据库，不进入公开响应、日志、日报、测试或仓库。新的发货方案固定 PDF，本地打印，云打印单独评估。

回退旧 Worker 前必须核实和排空新方案任务。地址与网点可编辑不代表供应商一定接受，应核对授权、实际承接范围和首次实单模板。

更多发货地、多账号授权或云打印需求出现时重新评估固定两方案模型。
