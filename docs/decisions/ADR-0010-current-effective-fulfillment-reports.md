# ADR-0010：按当前有效面单统计双渠道发货

- 状态：接受
- 日期：2026-10-08

## 背景

同一门店可由版纳或昆明履约，取消后可跨日跨渠道重发。累加出单、打印次数或按快递公司猜渠道会造成重复及错误库存参考。

## 决策

订单归属和渠道独立筛选。复用发货单及成功批次快照，以当前取号请求和有效业务状态只读聚合，不另建增减账、不修改打单/取消规则。取消只有供应商及本地确认成功才退出；重发按新日期/渠道/明细计一次。缺乏来源或日期证据的历史记录单列待核实，不猜测、不补写。

页面与 Excel 共用聚合逻辑、权限和筛选。页面用短只读事务；导出用在线备份的一致性快照与既有容量限制。只返回商品/归属汇总，不返回收件人或授权信息。可见页面轮询本系统，绝不为统计增加快递平台查询。

## 影响和重新评估

历史报表是“当前有效发货在原登记日期上的投影”，不是不可变的历史日末库存账；取消可改变历史日期的当前报表。将来接入进销存、实际出库确认或审计账时，需要独立的库存事件与审批设计，不能把此报表直接当库存余额。
